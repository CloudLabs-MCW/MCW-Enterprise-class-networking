## Exercise 8: Create a Network Monitoring Solution

### Estimated Duration: 20 Minutes

## 📘 Scenario

After deploying the enterprise networking infrastructure, the operations team at Woodgrove Financial Services requires centralized monitoring and diagnostics to track network activity, analyze traffic patterns, and support troubleshooting operations.

In this exercise, you will configure Log Analytics Workspace and Network Watcher to collect and monitor network telemetry and diagnostics.

## 📖 Overview

In this exercise, you set up a network monitoring solution in Azure, create a Log Analytics Workspace to collect and analyze logs, then, you verify Network Watcher is enabled for monitoring resources.

## 🎯 Objectives

In this lab, you will perform the following tasks:

- Task 1: Create a Log Analytics Workspace
- Task 2: Configure Network Watcher

### Task 1: Create a Log Analytics Workspace

In this task, you will create a Log Analytics Workspace in the MonitoringRG resource group. This workspace stores and analyzes monitoring data from network resources.

1. In the search bar of the Azure portal, type **Log Analytics Workspace (1)**. From the search results, select **Log Analytics Workspace (2)**.

   ![](images/ecn_p9_g_1.png)

1. Click on **+ Create**.

   ![](images/ecn_p9_g_2.png)

1. On the **Create Log Analytics workspace** blade, enter the following information:

    | Setting | Action |
    | -- | -- |
    | Subscription | **Select defualt subscription** **(1)**|
    | Resource group | **MonitoringRG** **(2)** |
    | Name | **workspace<inject key="DeploymentID" />** **(3)** |
    | Location | **East US** **(4)** |

1. It should look like the following screenshot. Validate that the information is correct, select **Review + create** **(5)**, and then **Create**.

    ![](images/ecn_p9_g_.png)

### Task 2: List the Network Watcher

In this task, you will verify that Network Watcher is available in the selected regions. This ensures monitoring and diagnostics are active for your network.

1. In the search bar of the Azure portal, type **Network Watcher (1)**. From the search results, select **Network Watcher (2)**.

   ![](images/ecn_p9_g_5.png)

1. In the **Overview** blade, ensure that **NetworkWatcher_southcentralus** and **NetworkWatcher_eastus** is listed.

   ![](images/ecn_p9_g_6.png)
